# Weather Dashboard ⛅🗺️

Aplicação web desenvolvida com React e TypeScript para consulta e visualização de informações climáticas de cidades ao redor do mundo.

## Funcionalidades 👷✔️

- Consulta de dados climáticos em tempo real
- Exibição de temperatura atual
- Exibição da sensação térmica
- Informações sobre condições climáticas
- Gerenciamento de cidades favoritas
- Interface responsiva

## Tecnologias Utilizadas 👨‍💻🧑‍🎓

- React
- TypeScript
- Vite
- Axios
- Context API
- OpenWeather API

## Instalação ⚙️🧑‍🏭

Clone o repositório:

```bash
git clone https://github.com/PedroHenrique06/Global-Weather.git
```

Acesse a pasta do projeto:

```bash
cd weather-dashboard
```

Instale as dependências:

```bash
npm install
```

## Configuração ⚙️👷‍♂️

Crie um arquivo `.env` na raiz do projeto:

```env
VITE_OPENWEATHER_API_KEY=sua_chave_aqui
```

Você pode obter uma chave gratuitamente através da plataforma OpenWeather.

## Executando o Projeto 🏃⏯️

Modo de desenvolvimento:

```bash
npm run dev
```

Build para produção:

```bash
npm run build
```

Pré-visualização da build:

```bash
npm run preview
```
